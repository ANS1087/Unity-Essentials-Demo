## 🧠 About This Project

This Unity project was built as part of the **Unity Essentials Pathway**, a beginner-friendly curriculum aimed at introducing key Unity features like:

- Scene setup and manipulation
- Working with GameObjects and prefabs
- Adding physics-based interactions
- Applying materials and lighting
- Basic scripting in C#
- Creating simple UI elements and interactivity


## 🛠️ Key Features Implemented

- **Interactive gameplay** using Unity's Rigidbody and Collider components.
- **Basic player input** to control game mechanics.
- **Use of prefabs** for reusable game elements.
- **Lighting and camera setup** for polished visuals.
- **UI elements** such as start and restart buttons.


## 💡 What I Learned

- Understanding Unity's component-based system
- Scene management and basic gameplay logic
- Organizing assets and working with prefabs
